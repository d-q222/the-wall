A small immigration firm's win rate on O-1 petitions should compound with every case it wins. Right now, no one lets it — because every petition is built entirely out of one person's identity.

A few of you in this room have filed one of these yourselves.

The problem

AI that forgets, vs. AI that learns

ABA Formal Opinion 512

A self-learning tool that lets one client's facts surface in another client's work needs specific informed consent. Boilerplate in an engagement letter is not enough.

Today's workaround

Zero-retention configs. Don't train on client input. The tool stays safe by learning nothing — so a firm's twentieth O-1 win teaches the AI nothing about the first nineteen.

We built memory that compounds the firm's know-how — how a strong O-1 case is built — without carrying any one beneficiary's identity into the next case.

What we're claiming — and not

Say: identifiers removed, residual leakage measured at X/n on held-out data.

Don't say: "de-identified," "anonymized," "HIPAA-compliant," "GDPR-compliant."

Consent duties under ABA 512 remain. What changes is that a two-lawyer immigration practice can start compounding its own win rate instead of starting from zero on every O-1 — with the residual risk measured, not assumed away.
